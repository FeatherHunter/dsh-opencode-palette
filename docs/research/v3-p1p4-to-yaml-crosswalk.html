6. 规矩

  • 裸 token 名只出现在 binds/token 字段与 direct_bindings 键上；用户 theme.yaml 只写能力 id。
  • 能力 → 底层实现技术：每条能力的 tech/binds 标明它落到 token / 规则 / DOM 哪一处。
  • 死名不冒充可用：status=dead 的 token 在直绑定里 tier=dead、exposure=不开放；能力菜单不生成对应语义能力。
  • 运行时只登记：tokens.yaml 的 runtime 段，不生成能力、不写入用户文件。
