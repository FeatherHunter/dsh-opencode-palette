三条结论（先看这个）：
  1. --dsl-* 大部分不是「新能力」，而是上游 token 的局部缩写：值里引用 var(--dsw-*) 的，改上游 token 即生效；不引用的（字体/圆角/行高/换行等结构性值）才需要规则层。

  3. 硬编码色里真正能救的只有 13 个 fallback：var(--token, #hex) 形式，设 token 即覆盖；其余 338 行是遮罩 alpha / 单体视觉色 / 注释，不在用户能力范围。

六、这批结果对 palette 的影响

  • --dsl-* 有上游 token 的：能力条目仍指向上游 token（不新增一条私有变量能力，避免重复表达；符合你「一个 token 一个语义」）。
  • 结构性的（字体/圆角/行高/换行）：新增规则层能力，值类型 = font/length/number/keyword。
  • --terminal-cursor*：新增 4 条运行时能力，tier = 实验（重渲染需重放）。
  • 硬编码 fallback：不新增能力（已被对应 token 覆盖）。
