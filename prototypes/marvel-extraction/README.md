## 判尺：四级，每一色都要能说清自己来自画面哪一块

| 级 | 定义 | 条数 |
|---|---|---|
| **A1 实涂直采** | 该 hex 在图中逐像素出现 **≥500 次** —— 被设计者真正平涂过的色 | 9 |
| **A2 边阶直采** | 出现 **50–499 次**，且能被证明是**两个平涂色的渲染器抗锯齿混合**（误差 ≤ 0.54/255） | 11 |
| **B 簇采** | 中位切分**簇心**：图里没有这个字面值，它代表一片 ΔE76 ≤ 10 的**实际区域** | 15 |
| **C 阶梯派生** | 以图里某个源色的 a\*/b\* 为基准，**只把 L\* 走到目标明度** | 2 |

A1/A2 逐像素在图里，B 落在图里某片区域，C 的源色逐像素在图里 —— **没有一色来自图外臆造**。

> 这一版改判尺是被对抗式审查逼出来的。上一版写「37/37 直采」，但按图里的真实体量，
> 只有 9 条是字面像素；14 条是簇心（图里根本没有这个字面值），12 条只出现 1–29 px，
> 是压缩噪声。拿「1 px」当溯源看着严谨，实则没有信息量。新判尺把这件事摊开写。

## 跑法

```powershell
cd prototypes\marvel-extraction
```

## 设计要点

- **主品牌不是标志红**：标志红 `#F11E22` 反白只有 3.83:1，撑不起主按钮。
  改用铁人战甲红 `#D32B28`，反白 **4.61:1**，色相 358°→1° 一帧未让。
- **焦点环与主按钮主动拆开**：`borderActive` 用最亮的标志红（焦点环要最醒目），
  `primary` 用能反白的战甲红（按钮要能承载白字）。v3 记档的「primary = borderActive」
  并岗因此解除，岗位串戏从 1 处降到 **0 处**。
- **第二品牌是熔金不是通用蓝**：铁人盔甲本体是金。primary ↔ secondary 色相差
  **33.8° = 类比**几何（暖对暖），比旧版红蓝 145.9° 的互补更接近海报质感。
- **8 级表面同族、只靠明度分层**：codeBlockBg `#000000`（L*0.00）→ background
  `#0C0C10`（3.42）→ sidebarBg `#121216`（5.59）→ inputBg `#18181C`（8.41）→
  bubbleBg `#1C1C22`（10.50）→ backgroundPanel `#252529`（14.83）→
  backgroundElement `#2D2D32`（18.65）→ codeHeaderBg `#333337`（21.38）。
  台阶 3.42/2.17/2.82/2.10/**4.32**/3.82/2.74，0 个色相孤岛。
- **那个 4.32 的空洞是被数学逼出来的**：primary 配白字要 4.5:1（Y ≤ 0.1604），
  同时 primary @backgroundPanel 要 3:1，两条联立推出 backgroundPanel 的
  Y ≤ 0.0191（L* ≤ 14.83）—— 卡片面不能更亮，否则深红 primary 够不到 3:1；
  而源图在 10.50 与 14.83 之间没有墨，台阶只能在这里留一个空洞。
- **退后两档是最省的一次分离**：comment / operator 必须比任何核心语法色都暗，
  又要 ≥4.5:1，被夹在极窄的亮度带里；画面该带只有冷灰与暖灰两种，于是
  冷灰 `#7A7A7F` 给注释、暖褐 `#9D7A72` 给运算符，ΔE 17.2。
- **语法五核心** keyword `#F44A4D` / function `#E4A05A` / type `#FFCB05` /
  number `#A0A2AC` / string `#F0E5D8`，两两 ΔE76 最小 **28.0**（门槛 10）。
