## 0. 审查的三条规矩

1. **先问这个色的工作是什么，再问它好不好看。** 每个色位在 DSH 里落到哪个 CSS 变量，是客观事实（`map-dsh.ts` 是唯一真相源），不是观感问题。

3. **不看自己的稿，看真值。** 拿 `map-dsh.ts` 的 token map、拿源码里的 `ensureDiffContrast` 语义、拿色位之间的数值关系，去反驳我自己写的那套叙事。

## 4. 仍然开放、我不替你拍板的四个问题

**Q1 · 主题的温度 = 参考图的温度。**
三张图全是正午高调画面，所以这套稿读起来是"夏日海滩"，不是"伟大航路"。这是**素材属性，不是 IP 属性**——仓库现有 notes 给的是「深海夜航」。要后者，得给夜景参考图；换句话说，这套稿和参考图是一套的，跟「海贼王」这个 IP 不是一套的。

**Q2 · 主色该是草帽金还是背心红？**
仓库现有 notes 明写「primary 草帽黄 #FFCC33（第一眼标志，比通用红更唯一）」。浅底上亮金过不了 3:1，只能用压深的黄铜。若把主色还给**深麦金 `#8A6A14`**（白字 4.96:1、UI 4.40:1，同样过审），CTA 就从"跳出来的红"变成"沉着的黄铜"，几何仍是 42.8° 类比。**两行配方可换，取舍是审美不是合规。**

**Q3 · 焦点环是全主题余量最薄的一处。**
`borderActive` 在引擎里用得最广（border-l2/l3/l4 + ghost-active-border + scrollbar-hover），但它 @ 最深浮层只有 **3.33:1**（阈值 3.0，余量 +0.33）。换成「航线深蓝 `#144DA5`** 可到 **5.13:1**，代价是草帽金在界面里只剩图标一处。

**Q4 · 溯源表比真实色相身份"好看"。**
25 个设计角色靠 23 个锚点，其中 `p_navy`（乌索普藏青）一个锚点服务 **12** 个角色、`navy_shadow` 服务 **8** 个——大量角色其实是"深海军蓝 + 一点点别的东西"。真正带色相身份的对象只有 8–9 种（天蓝 / 海军蓝 / 潟湖青 / 红 / 橙 / 麦金 / 绿 / 沙），要真正拉开需要更多不同色相的物件（火焰、恶魔果实的饱和色），**而三张参考图里没有**。
