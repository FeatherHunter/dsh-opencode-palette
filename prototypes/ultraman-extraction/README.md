# ultraman-extraction —— 奥特曼 IP 预置主题的取色与自检管线

本目录是 `src/custom-presets/ultraman.json`（奥特曼 / dark / 37 色位）的**取色与验证出处**。
色板里每一个色值都能在这里回答两个问题：**它从哪张图的哪个像素来**、**它过不过仓库判尺**。

## 跑法

```powershell
python prototypes/ultraman-extraction/build_palette.py
# 或把输出同时存成报告
python prototypes/ultraman-extraction/build_palette.py > prototypes/ultraman-extraction/report.txt
```

依赖：Python 3 + numpy + Pillow（DSH 自带运行时里都有）。
脚本**自己从参考图重读像素**得出颜色，再与 `EXPECTED`（出货值）逐位比对——换图或换解码器会当场报错而不是默默出一份新色板。

## 三条来源规则

1. **直采**（26 槽）：色值必须**等于参考图某张图的某个像素**。脚本按坐标重读像素验证。
2. **阶梯**（7 槽 + 画布）：8 个表面槽是画布 `#000600`（2.jpg (12,224)，44 px）染海报标题靛 `#2D2C8A`（images.jpg (256,25)，11 px）的明度阶，每档 α 由目标 L\* 反解。
3. **混色**（4 槽）：4 个 diff 底把直采的 `diffAdded` / `diffRemoved` 按固定 α（0.13 / 0.20）染在画布上。

## 判尺

脚本自检四层，与仓库的判尺同口径（相对亮度按 sRGB 线性化）：

- **house 判尺 53 对**：硬性 4.5 ×38（正文 8 表面 / 次级文字 / 弱化文字 / markdown 6 角色 / 语法 7 色 / diff / 按钮反白）+ UI 3.0 ×15（描边焦点环 / 品牌 6 角色）。仓库真源是 `scripts/audit-themes.ts`，本脚本是同一组对的独立复算。
- **宿主现实 49 对**：按 `app.asar` 里宿主的真实用法补判（12–14px 文字角色、实心填充配白字、2px 焦点环、8px 状态圆点、自染底、侧栏选中强调底……）。
- **设计规范 4 项**：角色同值碰撞、markdown 同值、品牌几何（primary↔secondary 色相差）、语法核心 ΔE76 与退后梯队。
- **色盲四态**：宿主 8px 状态圆点的 normal / deutan / protan 最小 ΔE76。

## 诚实边界

- **JPEG 里没有平坦像素**：26 个直采色全部落在边缘过渡处（5×5 邻域极差 43–255）。「等于原图某像素」保证的是**没有一个标志性颜色是想象出来的**，不等于「取到了一大片实色」——别把这两件事混为一谈。
- **单像素敏感**：多数直采色在原 JPEG 里只出现 1 次，换解码器或重存可能带来 ±1 偏移。
- **11 个混合槽按构造不是原图像素**，是可复算配方（α 精确到 4 位小数）。
- **已知限制 3 条**：`primary` 同时是宿主的文字色角色（`--dsw-alias-state-business-primary`），在 12% / 20% 自染底与页面底上是 3.55–4.00:1，达不到 4.5。这不是本套独有：house 24 套里 6 套暗色红主题同病（3.36–3.85:1），我们比它们好。
